## 1. Adaptación Dual por Contexto de Dispositivo

### 1.1 Experiencia Android (Móvil / Táctil)
- Zonas táctiles de al menos 44px de altura para botones de corte (`Dividir`, `Duplicar`, `Eliminar`, `In`, `Out`).
- Barra de navegación con desplazamiento horizontal suave compatible con gestos táctiles.
- Cabezal de tiempo táctil tipo scrubber deslizable sin conflicto con el scroll general.

### 1.2 Experiencia Escritorio (Ratón y Teclado)
- Selección precisa de clips con ratón.
- Distribución espaciosa de 12 columnas (7 columnas para monitor y timeline, 5 columnas para inspector).
- Visualización compacta de timecode SMPTE y métricas de escala zoom.
